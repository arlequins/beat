## 에이전트는 문서가 없으면 추측한다

Next.js는 프로젝트 버전에 맞는 지침을 `AGENTS.md`로 제공하고, 브라우저 로그를 터미널로 전달하는 기능을 지원합니다. React 상태를 확인하는 브라우저 도구와 MCP도 실험하고 있습니다. 에이전트가 코드를 바꾸기 전에 프레임워크 규칙과 실제 실행 중 발생한 오류를 확인하도록 돕는 변화입니다.

## “고쳐줘”를 재현 가능한 입력으로

브라우저 오류를 복사해 전달하는 대신 URL, 로그, 컴포넌트 상태, 재현 단계를 일정한 형식으로 제공하면 에이전트가 고친 내용을 검증하기 쉬워집니다. 로그에 토큰이나 개인정보가 섞이면 개발 편의 기능이 새로운 정보 유출 경로가 될 수 있습니다.

## 프로젝트에 들이는 최소 경계

저장소 지침과 실제로 실행할 검증 명령, 수정하면 안 되는 파일과 비밀 정보 취급 규칙을 먼저 적습니다. 에이전트의 권한은 읽기, 쓰기, 배포로 나누고 최종 병합은 사람이 승인하도록 합니다.
