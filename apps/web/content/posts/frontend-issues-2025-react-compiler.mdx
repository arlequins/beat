## 최적화 코드를 덜 쓰게 된다는 뜻

React Compiler 1.0이 안정 버전으로 출시됐습니다. 컴포넌트와 훅을 분석해 필요한 메모이제이션을 자동으로 적용합니다. 개발자는 `useMemo`와 `useCallback`을 습관적으로 덧붙이는 대신, 의도가 분명한 렌더링 코드를 작성할 수 있습니다.

## 자동화가 설계를 대신하지는 않는다

컴파일러는 비싼 계산의 원인, 과도한 전역 상태, 네트워크 경계, 잘못된 키를 해결하지 않습니다. 도입 전후로 상호작용 지연과 렌더링 횟수를 같은 시나리오에서 측정하고, 컴파일러가 건너뛴 코드가 있다면 이유를 기록해야 합니다.

## 안전한 도입 순서

먼저 린터와 컴파일러 설정을 CI에 넣고, 작은 화면부터 선택적으로 적용합니다. 성능이 나빠지면 수동 메모이제이션을 더하기보다 컴포넌트의 역할과 데이터 흐름을 다시 살펴봅니다. 자동 최적화의 가치는 코드 양이 아니라 측정할 수 있는 사용자 경험으로 판단해야 합니다.
