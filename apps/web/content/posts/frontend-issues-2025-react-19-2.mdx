## 화면을 숨겨도 상태를 유지하는 Activity

React 19.2의 `<Activity />`는 화면을 완전히 없애는 대신 보이지 않게 숨기고, 그 화면에서 처리할 작업의 우선순위를 낮출 수 있게 합니다. 탭이나 작성 중인 폼처럼 다시 돌아올 화면의 상태를 유지하는 방법이 하나 더 생겼습니다.

## 효과의 실행 시점과 성능 기록이 분명해진다

`useEffectEvent`를 쓰면 사용자 이벤트에 따른 로직과 렌더링에 반응하는 효과를 구분하기 쉬워집니다. Performance Tracks는 브라우저 성능 기록에서 React 작업을 더 쉽게 살펴보도록 돕습니다. 두 기능은 최적화에 앞서 각 작업이 언제 실행되는지 확인하게 합니다.

## 적용할 때의 질문

Activity를 도입하기 전에 숨겨진 화면이 메모리와 접근성에 어떤 영향을 주는지 확인합니다. 효과를 바꾸기 전에는 외부 시스템 동기화인지 사용자 이벤트인지 분류합니다. 새 API는 멋진 문법보다 상태 보존과 측정 가능성을 개선할 때 가치가 있습니다.
