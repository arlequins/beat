> Chrome for Developers의 2025 Web UI 정리를 바탕으로 한 공개 미확정본입니다.

## 가장 흔한 UI가 가장 비쌌다

select, popover, anchored menu는 흔하지만 포커스·닫힘·화면 가장자리 처리를 직접 구현해야 했습니다. 2025년에는 Popover API와 anchor positioning이 여러 브라우저에서 안정되는 흐름이 빨라졌습니다.

## 디자인 시스템의 책임 재배치

브라우저가 기본 상호작용을 맡으면 디자인 시스템은 색·간격·모션·제품 규칙에 집중할 수 있습니다. 반대로 네이티브 API를 감싼 컴포넌트가 접근성 이름과 키보드 동작을 망가뜨리지 않는지 테스트해야 합니다.

## 채택 기준

지원 브라우저가 Baseline에 들어왔는지 확인하고, 기존 polyfill과 중복되는지 살펴봅니다. 한 번에 모든 컴포넌트를 바꾸지 말고 메뉴 하나를 네이티브 경로로 옮겨 키보드·스크린리더·모바일 회귀를 비교합니다.
