## 흔한 UI도 직접 만들면 손이 많이 간다

select, popover, anchored menu는 흔히 쓰이지만 포커스 이동과 닫힘, 화면 가장자리 처리를 직접 구현해야 했습니다. 2025년에는 여러 브라우저가 Popover API와 anchor positioning을 안정적으로 지원하기 시작했습니다.

## 디자인 시스템의 책임 재배치

브라우저가 기본 동작을 제공하면 디자인 시스템은 색상과 간격, 움직임, 제품별 규칙에 집중할 수 있습니다. 다만 네이티브 API를 감싼 컴포넌트가 접근성 이름과 키보드 동작을 제대로 유지하는지는 따로 확인해야 합니다.

## 채택 기준

지원 브라우저에서 Baseline 기준을 충족하는지 확인하고 기존 폴리필과 기능이 겹치는지도 살펴봅니다. 모든 컴포넌트를 한꺼번에 바꾸지 말고 메뉴 하나부터 네이티브 API로 옮겨 키보드와 스크린 리더, 모바일 동작을 비교합니다.
