## 1. GPT-6.1 Sol: 낮아진 단가를 도입 기준으로 삼되 결과도 다시 재기

OpenAI는 9월 29일 GPT-6.1 Sol을 공개했습니다. 회사 발표 기준으로 API 입력·출력 단가는 GPT-6 Astra의 5분의 1이며, 캐시 입력은 백만 토큰당 0.10달러입니다. 코딩과 컴퓨터 사용을 포함한 평가에서 이전 GPT-6 Sol보다 개선됐다고 밝혔지만, 이 결과는 OpenAI의 평가 환경에 기반하며 운영 앱에서의 품질을 대신 보장하지는 않습니다. 같은 날 API 변경 기록에는 Agents API의 호스팅 브라우저 computer-use 기능과 웹사이트 접근 승인이 함께 소개됐습니다.

기존 모델을 바로 바꾸기보다 자주 실행하는 업무 몇 가지를 고정 평가 세트로 만드세요. 정확도와 수정 필요 비율, p95 응답 시간, 캐시 적중률, 실제 요청당 비용을 나란히 비교하고, 사용 가능한 도구와 사이트를 작업별로 제한합니다. 비용 절감이 확인돼도 쓰기·배포처럼 되돌리기 어려운 단계에는 명시적 승인과 재현 가능한 로그를 유지합니다.

출처: [OpenAI: GPT-6.1 Sol 소개](https://openai.com/index/introducing-gpt-6-1-sol/), [OpenAI API 변경 기록](https://developers.openai.com/api/docs/changelog)

## 2. GitHub Copilot computer use: API 없는 데스크톱 작업에도 권한 경계를 세우기

GitHub는 10월 1일 Copilot CLI와 macOS·Windows용 Copilot 앱에서 데스크톱 앱 조작 기능을 공개 미리보기로 제공한다고 발표했습니다. Copilot은 앱의 접근 가능한 내용과 화면 맥락을 보고, 버튼을 누르거나 텍스트를 입력하며 앱 사이의 절차를 진행할 수 있습니다. 사용자가 앱 제어를 승인하도록 하고, macOS에서는 손쉬운 사용과 화면 기록 권한도 안내합니다. 조직 관리자는 기능을 비활성화할 수 있습니다.

시범 적용은 민감한 계정이 없는 개발용 가상환경이나 테스트 프로필부터 시작하세요. 허용 앱과 파일을 최소화하고, 제출·결제·삭제처럼 외부 상태를 바꾸는 조작은 사람 확인을 남깁니다. 실행 기록에는 대상 앱, 수행한 조작, 결과, 승인자를 연결해 두면 GUI 자동화가 실패했을 때 원인을 추적하기 쉽습니다. 데모가 성공했다는 이유만으로 운영 계정에 권한을 넓히지는 마세요.

출처: [GitHub Changelog: Copilot의 데스크톱 앱 computer use](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps/)

## 3. macOS Full Disk Access: 넓은 권한을 쓰는 앱과 SDK를 미리 목록화하기

Apple은 10월 2일 Full Disk Access가 파일뿐 아니라 메일, 메시지, 브라우징 기록까지 노출할 수 있다고 경고하고, 앞으로 사용자가 이 권한을 더 명확한 동작으로 허용하도록 추가 통제를 도입하겠다고 밝혔습니다. 특히 통신 앱은 사용자가 아닌 상대방의 개인정보에도 영향을 줄 수 있다고 설명합니다. 발표에는 적용 시점이나 구체적인 API 변경 일정은 아직 포함되지 않았습니다.

앱과 포함된 SDK 중 Full Disk Access에 의존하는 항목을 조사하고, 파일 선택기나 제한된 폴더 접근처럼 좁은 권한으로 대체할 수 있는지 확인하세요. 계속 필요한 경우에는 사용 이유와 수집 범위를 제품 설명과 개인정보 안내에서 구체적으로 밝힙니다. Apple의 후속 개발자 공지가 나오면 권한 허용 화면, 자동화 테스트, 지원 문서를 함께 점검할 담당자와 일정을 정해 둡니다.

출처: [Apple Developer: macOS Full Disk Access 변경 안내](https://developer.apple.com/news/?id=p6zjojqw)
