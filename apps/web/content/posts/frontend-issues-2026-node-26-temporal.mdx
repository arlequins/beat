## 날짜를 문자열로만 다룰 때 생기는 문제

Node.js 26에서는 Temporal API를 별도 설정 없이 사용할 수 있습니다. `Date`에서 모호했던 시간대와 달력, 값 변경 문제를 다루는 표준 API가 서버 런타임에 기본으로 들어온 것입니다.

## SSR과 브라우저의 일치

서버에서 `Temporal.ZonedDateTime`을 사용하더라도 JSON으로 전달할 때는 형식을 명시해야 합니다. 브라우저가 지원하는지, 폴리필 용량은 어느 정도인지, 날짜를 어떤 시간대로 보여줄지 정해야 합니다. 서버만 새 API를 쓰면 하이드레이션 결과가 달라질 수 있습니다.

## 도입 체크리스트

먼저 회계와 예약처럼 시간대가 중요한 기능에서 날짜를 어떤 형식으로 다룰지 정합니다. API에는 UTC 기준 시각과 화면에 표시할 시간대를 구분해 담습니다. 기존 `Date`를 한꺼번에 교체하기보다 새 모듈부터 Temporal을 적용하고 직렬화 테스트를 추가하는 편이 좋습니다.
