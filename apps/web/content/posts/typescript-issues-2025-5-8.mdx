## 타입 검사는 의도를 더 가까이 본다

TypeScript 5.8은 조건부 반환식의 각 분기를 더 꼼꼼하게 검사합니다. 캐시된 값을 반환하거나 새 값을 만드는 코드에서 분기별 타입을 확인해, 놓치기 쉬운 오류를 컴파일할 때 찾아낼 수 있습니다.

## `assert`에서 `with`로

Node.js를 비롯한 모듈 생태계가 import attributes를 도입하는 흐름에 맞춰 JSON import의 `with { type: "json" }` 문법을 지원합니다. TypeScript 문법 자체보다 실행 환경과 도구가 같은 표준을 따라가고 있다는 점을 보여주는 변화입니다. `module`과 `moduleResolution`을 함께 설정하고 실제 런타임에서 확인해야 합니다.

## 마이그레이션 체크리스트

반환식이 복잡한 유틸리티부터 CI에서 새 컴파일러로 검사하고, JSON import는 번들러와 Node 실행을 각각 테스트합니다. 타입 버전만 올리는 것이 아니라 패키지의 ESM·CJS 경계를 같이 기록하는 것이 핵심입니다.
