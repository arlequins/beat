## 프런트엔드 도구의 기반인 Node.js도 바뀐다

Node.js 24에는 V8 13.6과 npm 11이 포함됐습니다. `URLPattern`을 전역에서 사용할 수 있고 `AsyncLocalStorage`의 기본 구현도 바뀌었습니다. 브라우저 코드만 다루는 팀이라도 개발 서버와 테스트 도구, 사전 렌더링 환경이 어떤 Node.js 버전을 요구하는지 확인해야 합니다.

## 비동기 컨텍스트의 의미

AsyncContextFrame은 요청 추적이나 로그 기록처럼 비동기 작업 사이에 맥락을 전달하는 기능에 영향을 줍니다. 프레임워크가 이 변화를 어떻게 처리하는지 확인하지 않으면 로컬과 CI에서 기록되는 결과가 달라질 수 있습니다.

## LTS 전에 할 일

Current 버전을 곧바로 운영 환경에 적용하기보다 CI 테스트에 추가해 호환성을 확인합니다. 패키지 관리자와 네이티브 모듈, Playwright 브라우저 버전도 함께 관리하고, 10월 LTS 전환 때 도입 여부를 다시 판단합니다.
