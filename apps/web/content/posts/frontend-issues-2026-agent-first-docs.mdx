## 문서는 실행 전에 확인하는 사용 설명서다

버전에 맞는 `AGENTS.md`와 Markdown 문서, 해결 방법을 알려주는 오류 메시지는 에이전트가 오래된 글이나 추측에 기대지 않도록 돕습니다. 에이전트가 프레임워크를 사용하게 되면 문서를 찾기 쉽고 최신 상태로 유지하는 일도 제품 품질의 일부가 됩니다.

## 사람도 같은 혜택을 받는다

에이전트가 읽기 좋은 문서는 사람도 필요한 내용을 빠르게 찾고 검증하기 쉽습니다. 명령을 실행하기 위한 조건과 바뀌는 파일, 실패했을 때 할 일을 짧게 적어두면 새 팀원의 적응과 장애 대응에 모두 도움이 됩니다.

## 저장소에 적용하기

저장소 루트에는 공통 원칙만 적고 앱과 패키지별 버전, 실행 명령은 해당 위치에 정리합니다. 비밀 정보와 개인 환경 설정은 문서에 넣지 않습니다. CI에서 문서에 적힌 명령을 실행해 실제 동작과 설명이 어긋나지 않는지도 확인합니다.
