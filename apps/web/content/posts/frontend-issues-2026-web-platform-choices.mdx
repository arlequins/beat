## “모던 브라우저”라는 말은 부족하다

Baseline은 웹 기능이 주요 브라우저에서 어느 정도 지원되는지 공통 기준으로 보여줍니다. Vite는 이를 기본 빌드 타깃에 반영했고, 프레임워크도 빌드 결과가 어떤 브라우저 기능에 기대는지 더 분명히 드러내고 있습니다.

## 지원 정책은 코드보다 먼저다

사내 WebView나 보급형 Android 기기, 검색 크롤러처럼 일반적인 브라우저 범위 밖의 대상도 지원한다면 별도 정책을 정해야 합니다. “Baseline이니까 된다”고 가정하지 말고 지원 대상과 점진적 향상, 대체 경로를 테스트 항목에 넣어야 정책이 실제로 작동합니다.

## 올해의 실천

브라우저 타깃을 `package.json`과 번들러 설정에 흩어 두지 말고 한 문서에서 관리합니다. CSS와 Web API, JavaScript 문법별 Baseline 지원 상태와 대체 경로를 기록하고, 분기마다 실제 사용자 비율에 맞춰 갱신합니다.
