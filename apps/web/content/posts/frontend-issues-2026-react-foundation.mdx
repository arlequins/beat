## 프레임워크의 기반도 운영 대상이다

React Foundation은 React와 관련 프로젝트를 Linux Foundation 아래에서 지속해서 관리하고 의사결정할 체계를 만들려는 움직임입니다. 제품팀도 라이선스와 출시, 호환성을 누가 어떤 절차로 결정하는지 살펴봐야 합니다.

## 기업 의존에서 생태계 계약으로

한 회사의 로드맵만 확인하던 팀이라면 이제 유지보수 주체와 RFC 절차, 주요 파트너의 역할도 살펴봐야 합니다. 모든 선택을 다시 검토할 필요는 없습니다. 다만 내부 컴포넌트가 특정 실험 기능에 종속되지 않도록 공개 API와 업그레이드 경계를 유지해야 합니다.

## 포트폴리오에 남길 질문

기술을 선택할 때 “누가 만들었나?”뿐 아니라 “누가 계속 검증하고, 호환성 문제가 생기면 어떻게 대응하나?”도 기록합니다. 거버넌스가 미래를 보장해 주지는 않지만, 변화의 배경과 대응 절차를 확인하는 데 도움이 됩니다.
