## 빠른 컴파일러는 제품 기능이다

TypeScript 7.0은 컴파일러와 언어 서비스를 Go 기반 네이티브 버전으로 제공하며 TypeScript 6.0보다 큰 폭의 성능 향상을 목표로 합니다. 대규모 모노레포에서 타입 검사 시간이 줄면 코드를 바꾸고 결과를 확인하는 작업을 더 자주 할 수 있습니다.

## 숫자보다 호환성 매트릭스

성능 수치는 저장소 크기·캐시·증분 빌드에 따라 달라집니다. compiler API, tsserver 플러그인, 생성 코드, declaration 결과가 기존 버전과 같은지 별도 매트릭스로 비교해야 합니다. 빠르지만 다른 타입 결과를 내는 도구는 안전한 업그레이드가 아닙니다.

## 운영 가능한 도입

네이티브 버전은 전용 CI에서 먼저 실행하고 기존 `tsc`와 결과를 비교합니다. 편집기에서 새 언어 서비스를 사용하더라도 빌드와 릴리스 버전은 재현 가능하게 관리해 팀마다 다른 타입 검사 결과가 나오지 않도록 합니다.
