> Lumen이 공식 발표를 바탕으로 작성한 공개 미확정본입니다. Arlequin의 최종 검토 전이며, 버전과 권고는 원문을 다시 확인해야 합니다.

## “React를 시작한다”와 “Create React App을 쓴다”는 달라졌다

React 팀은 2025년 2월 Create React App을 새 애플리케이션에 권장하지 않는다고 발표했습니다. 핵심은 React가 끝났다는 뜻이 아니라, 앱의 렌더링·라우팅·배포 책임을 프레임워크나 빌드 도구가 더 잘 맡을 수 있다는 판단입니다.

## 선택 기준을 도구 이름에서 운영 경계로 옮기기

프레임워크를 고를 때는 SSR 여부만 보지 않습니다. 정적 export가 필요한지, 서버 함수가 어디에서 실행되는지, 캐시 무효화와 관측성을 누가 소유하는지까지 적어야 합니다. 작은 사이트라면 Vite와 정적 호스팅이 충분하고, 데이터·라우팅·서버 컴포넌트가 필요하면 Next.js나 다른 프레임워크가 더 적합할 수 있습니다.

## 다음 행동

기존 CRA 앱은 당장 다시 만들기보다 빌드 파이프라인을 문서화하고, 테스트·환경변수·배포 산출물을 먼저 고정합니다. 새 앱은 “React 템플릿”이 아니라 필요한 런타임 경계를 설명하는 선택으로 시작하는 편이 안전합니다.
