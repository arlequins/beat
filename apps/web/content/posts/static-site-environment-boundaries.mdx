정적 사이트는 빠르고 운영 부담이 낮습니다. 하지만 공개 환경변수, API 주소, 인증 콜백 URL처럼 배포 시점에만 정해지는 값도 있습니다. 이 값들을 코드와 분리해 두면 로컬 개발과 배포 환경을 안전하게 오갈 수 있습니다.

특히 브라우저에 포함되는 값은 공개되어도 되는 값만 사용해야 합니다. 데이터베이스 비밀번호나 서버 토큰은 서버 환경변수에만 두고, 프런트엔드에는 API 주소와 공개 클라이언트 ID처럼 노출을 전제한 값만 전달합니다.
