# Beat Product Studio

Beat의 운영 화면은 블로그 관리자와 개인 기록 보관함을 하나의 흐름으로
연결한다.

## 운영 보드

`/admin/`에 로그인하면 먼저 다음 상태를 확인할 수 있다.

- 전체 콘텐츠, 검토 필요, 확정·발행 콘텐츠 수
- 공개 Gourmet 기록 수
- 최근 수정된 기사와 바로가기
- 제목·슬러그·카테고리·검토 상태가 비어 있거나 미확정인 콘텐츠
- Beat Agent와 Gourmet 작업 공간으로의 빠른 이동

품질 확인 수치는 자동 차단이 아니라 편집자가 확인할 다음 작업을 알려주는
신호다. 확정은 기존과 같이 S3의 새 불변 리비전과 GitHub 검토 요청을 거친다.

## 게시글에서 Agent로 연결

게시글 하단의 `이 글을 Beat에게 묻기`는 제목·공개 URL·발췌만 Agent의 새
대화로 전달한다. 토큰, 관리자 세션, 다른 브라우저 데이터는 전달하지 않는다.
Agent의 로그인과 대화·출처·피드백 보관은 Beat Agent가 담당한다.

`NEXT_PUBLIC_BEAT_APP_URL`이 설정되지 않은 빌드에서는 연결 카드가 렌더링되지
않는다. URL 파라미터는 짧게 제한하며, 비공개 원문이나 Gourmet 관리자 데이터는
이 경로로 보내지 않는다.

## Gourmet 타임라인

공개 Gourmet 화면은 최신 월부터 월별 타임라인으로 기록을 묶고, 다음 요약을
제공한다.

- 전체 기록 수
- 평균 평점
- 재방문 추천 수
- 지역·식당 검색과 사진 카드

사진은 계속 private S3에 보관하고, 공개 화면은 API가 허용한 이미지만 읽는다.
관리자에서 원본을 수정하거나 삭제하면 공개 상태와 리비전 규칙은 기존 Gourmet
API를 따른다.

## 다음 확장 지점

이 화면을 확장할 때도 자동 발행보다 확인 가능한 제안을 우선한다.

1. 출처별 신뢰도와 오래된 링크를 콘텐츠 품질 신호에 추가
2. Gourmet 장소별 재방문·태그 통계와 지도 뷰 추가
3. Agent 답변에서 게시글·Gourmet 리비전으로 돌아오는 링크 추가
4. 모바일 PWA 임시 저장과 음성 메모를 추가하되 원본 확인 단계를 유지
