# ChatGPT 사진 확장 프로그램 폐기 안내

Beat의 개인용 Chrome ChatGPT 사진 확장 프로그램은 폐기되었습니다.

- 새 릴리스에는 확장 ZIP 또는 체크섬이 첨부되지 않습니다.
- 기존에 배포된 ZIP은 호환성과 보안 업데이트를 보장하지 않습니다.
- Chrome에서 설치된 확장은 `chrome://extensions`에서 제거해야 합니다.
- 사진은 Beat 관리자 화면의 수동 업로드 또는 승인된 ChatGPT MCP 흐름을
  사용해야 합니다.

이 문서는 과거 릴리스 자산을 설치한 사용자가 안전하게 제거할 수 있도록
남겨 둔 공지입니다.
