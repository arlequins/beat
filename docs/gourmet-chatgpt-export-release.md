# Beat Gourmet ChatGPT Exporter 릴리즈

이 문서는 Beat 릴리즈에서 제공하는 ChatGPT Gourmet 이미지 내보내기 확장 프로그램을 설치하고 안전하게 사용하는 방법을 안내합니다.

## 설치

1. 최신 `beat-v*` 릴리즈의 `beat-gourmet-chatgpt-export-v*.zip`과 같은 이름의 `.sha256` 파일을 다운로드합니다. ZIP 안의 확장 버전은 해당 Beat 릴리즈와 자동으로 맞춰집니다.
2. ZIP 파일의 SHA-256 해시가 체크섬 파일과 일치하는지 확인합니다.
3. ZIP을 압축 해제하고 Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드**로 압축 해제한 폴더를 선택합니다.

## 사용 경계

- 먼저 같은 브라우저 프로필에서 Beat Admin에 로그인하고, 내보낼 원본 ChatGPT 대화를 엽니다.
- 확장 프로그램은 현재 로그인된 ChatGPT 화면에서 이미지 원본을 읽어 Beat Gourmet의 기존 `draft` 기록에만 연결합니다.
- 확장 프로그램은 기록을 생성하거나 공개하지 않으며, 기존 Beat Admin 세션의 단기 토큰만 사용합니다.
- 공유 링크나 다른 브라우저 프로필에는 원본 이미지 바이트가 없을 수 있으므로, 이미지가 표시되는 로그인된 원본 대화에서 실행해야 합니다.
- 같은 초안에 이미 연결된 사진은 자동으로 건너뛰므로 재시도해도 중복 사진이 생기지 않습니다.

Chrome Web Store 등록은 별도의 개발자 계정과 스토어 심사 절차가 필요합니다. 이 저장소의 릴리즈 자동화는 검증된 ZIP과 체크섬까지만 제공합니다.
